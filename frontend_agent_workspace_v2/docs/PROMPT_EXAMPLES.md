# Prompts de ejemplo

## Tabla
`Crea una tabla de usuarios con nombre, email, rol y acción Editar. Usa la skill de tablas y valida el resultado.`

## Panel + formulario
`Crea un panel con un formulario de alta. Usa las referencias locales, sin clases inventadas ni frameworks externos.`

## Extender CSS
`Necesito un patrón reutilizable para alertas. Amplía primero la referencia CSS, crea un ejemplo y valida el workspace.`

## Revisión
`Revisa examples/basic-guide.html con el quality gate y corrige únicamente los criterios que fallen.`
