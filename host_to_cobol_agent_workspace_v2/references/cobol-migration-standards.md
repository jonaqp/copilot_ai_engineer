# Standards de migracion HOST -> COBOL

- Preservar comportamiento antes de optimizar.
- Separar source y target.
- Inventariar dependencias y contratos antes de modificar.
- Trazar Source -> Target -> Test.
- Mantener contratos de datos explicitos.
- Usar COBOL estructurado y nombres descriptivos.
- Validar compilacion cuando el entorno lo permita y regresion cuando existan casos reproducibles.
- No esconder supuestos criticos.
