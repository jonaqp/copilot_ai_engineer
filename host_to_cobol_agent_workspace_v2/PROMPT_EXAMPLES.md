# Prompt examples

## Inventario
`Analiza el proyecto HOST demo. Lista programas, llamadas, layouts, jobs, I/O y riesgos. Clasifica evidencia/inferencia/supuesto.`

## Mapeo de datos
`Mapea ACCOUNT.rec a un COPYBOOK COBOL. Conserva orden, precision, signo y semantica. No inventes encoding.`

## Migracion incremental
`Migra solo ACCTUPD.host. No toques BALQRY ni BATCHSETTLE. Genera COBOL estructurado y trazabilidad source-target-test.`

## Limpieza
`Revisa el COBOL generado y reduce duplicacion, mejora nombres y paragraphs sin cambiar comportamiento.`

## Quality gate
`Ejecuta la validacion completa. Si falta compilador, no ocultes la limitacion y devuelve PASS WITH CONDITIONS.`
