# HOST -> COBOL Migration Engineer

Workspace de GitHub Copilot para migraciones HOST/Mainframe a COBOL de forma incremental, trazable y validada. Incluye agente, 5 skills, referencias, scripts deterministas y un proyecto legacy sintetico.

## Estructura
- `.github/agents/host-to-cobol-migration-engineer.agent.md`
- `.github/skills/`
- `references/`
- `scripts/`
- `demo_host_migration/legacy_host/`
- `demo_host_migration/target_cobol/`

La demo es sintetica y no incorpora formatos propietarios. Adapta parsers y mapeos a las convenciones reales del repositorio antes de usar en produccion.
