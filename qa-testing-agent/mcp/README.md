# MCP - qa-testing-agent

## Recomendado

- Remoto GitHub Enterprise BBVA: `remote/github-bbva.jetbrains.json`.
- Local GitHub Docker: `local/github-docker.jetbrains.json`.
- MCP de dominio local: `local/domain-local.jetbrains.json` (server id `qa-local`).
- Catálogo completo observado: `remote/catalog-all-observed.jetbrains.json` y `local/catalog-all-observed-local.jetbrains.json`.

No habilitar todo por defecto. Añadir al `mcp.json` de PyCharm solo los servidores requeridos.
