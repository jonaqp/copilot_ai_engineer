# Shared MCP

Configuraciones reutilizables para los MCP observados en el catálogo del taller y sus alternativas locales cuando existe una vía soportada.

- `remote-catalog.jetbrains.json`: GitHub Enterprise BBVA + Figma remoto.
- `local-catalog.jetbrains.json`: Cells Docs NPM + Figma Desktop + GitHub Docker.
- `github-toolsets-internal-reference-2026-07.json`: referencia histórica del allowlist interno localizado; **no sustituye el catálogo vigente**.

Copiar únicamente los servidores necesarios al `mcp.json` de PyCharm/JetBrains.
