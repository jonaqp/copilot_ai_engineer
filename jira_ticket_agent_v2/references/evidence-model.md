# Evidence model

- PASS: evidencia directa confirma la regla.
- FAIL: evidencia directa contradice la regla.
- WARNING: la regla se cumple parcialmente o requiere revision humana.
- UNKNOWN: no hay evidencia suficiente.
- UNKNOWN_VISUAL: existe metadata del adjunto pero no se pudo inspeccionar su contenido visual.

Nunca convertir UNKNOWN en PASS por intuicion.
