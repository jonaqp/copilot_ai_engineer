# Jira Ticket Quality Agent for GitHub Copilot

Agente de GitHub Copilot para leer, validar y corregir controladamente tickets Jira mediante `mcp-atlassian`.

Incluye:
- 1 agente principal;
- 6 skills especializadas;
- MCP local configurado sin token hardcodeado;
- perfil demo `deployment-datax` basado en las tres capturas de referencia;
- validacion de summary/description/readiness;
- validacion de adjuntos e imagenes;
- validacion de issue links y subtasks;
- quality gate READY / READY WITH CONDITIONS / NOT READY;
- demo offline con JSON y scripts deterministas.
