# GitHub Copilot Multi-Agent Orchestration Engineer

Workspace didáctico para demostrar un agente orquestador que descompone trabajo y coordina subagentes de integración, contratos, testing y validación. Incluye una demo SuperStore y un dashboard HTML generado desde una ejecución paralela real con Python `asyncio`.

```bash
python scripts/run_orchestration.py
python scripts/validate_workspace.py
```
Abrir `demo_orchestration/orchestration-report.html`.
